## RIFE

The 96-frame animation variants were generated offline with a RIFE 4.9 ONNX model. The model file is not included in this repository. The model repository used for the conversion is:

- [FuryTMP/RIFE_fp32](https://huggingface.co/FuryTMP/RIFE_fp32), MIT license.

The RIFE model is used only as an offline generation tool. The runtime plugin does not ship or call the model.
